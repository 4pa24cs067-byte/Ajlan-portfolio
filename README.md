# Muhammed Ajlan — Portfolio

A responsive, five-page portfolio built with plain HTML, CSS and JavaScript in the Minimalist Editorial style requested.

## Run locally
1. Extract the ZIP file.
2. Open the extracted `ajlan-minimalist-editorial-portfolio` folder in VS Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.

## Pages
- `index.html` — home and selected work
- `about.html` — profile, education and certification
- `projects.html` — project details
- `skills.html` — technical, foundation, tools and professional skills
- `contact.html` — email, phone and contact form

## Resume and photo
- Original resume: `public/resume.pdf`
- Supplied profile photo: `public/images/ajlan-photo.jpg`

## Contact details
The email and phone number shown are copied from the supplied resume. The contact form uses a `mailto:` link and opens the visitor's email application; it does not send messages through a server. GitHub and LinkedIn links are omitted because profile URLs were not provided.

## Design
Near-black monochrome palette, Instrument Serif display typography, Inter body text, DM Mono metadata, generous whitespace, fine divider lines, restrained hover transitions and responsive mobile navigation. Google Fonts requires an internet connection; fallback fonts are included.

## Accuracy note
Project roles, dates and descriptions follow the supplied resume. No extra frameworks, sensor models, programming languages or project claims have been added.
